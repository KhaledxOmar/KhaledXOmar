# Khaled Al-Noubi

I am a software engineering graduate from KFUPM (2024). I am building Murattab, which is an Arabic platform for teachers to publish and sell online courses.

I also help run an online academy with about 5,600 learners. This work made me interested in course data, especially text-to-SQL for Arabic questions, predicting learner drop-off, and feedback for learners.

Right now, I am building Murattab and studying in the KAUST Academy AI Specialization.
